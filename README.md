# jsocolar.github.io

Personal website for Jacob Socolar, published with GitHub Pages at <https://jsocolar.github.io/>.

## Local development

This site is built with Jekyll.

```sh
bundle install
bundle exec jekyll serve
```

Then open http://127.0.0.1:4000/.

Notes
The homepage uses a custom layout and stylesheet. Some legacy pages still use the older Jekyll/Minimal Mistakes structure so existing published URLs continue to work.
